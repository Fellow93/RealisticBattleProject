Legend and how the map is drawn
Attacker formation Defender formation Water (deep) Ford Woods Rough / steep Open field Hill top rings

Rectangles are width x depth at the formation's average position. The AI log has no facing: it is inferred from the order point (a Move point is the formation's front centre), the movement, or the nearest enemy. Terrain areas are ellipses from each feature's position, size along/across the battle axis and area; the log has no outlines, so shapes are approximate. Plans (spots, lanes, holds) show the latest version published at the current time. Dashed outline = player-controlled formation.
